[Description: English]
[Description]
This project is the sensorless vector control software that drives a permanent magnet synchronous motor (PMSM) using the RA4T1 microcontroller.

[Features, Target System]
 -Sensorless feedback
 -Vector control

[Hardware Setup]
 -CPU board : MCB-RA4T1 RA4T1(R7FA4T1BB3CFM) CPU board Version 2 (RTK0EMA430C00020BJ)
 -Inverter board : MCI-LV-1
 -Communication board : MC-COM
 -Motor : R42BLD30L3

[Supported QE function(s)]
 -SW configuration
 -Tuner
 -Analyzer

[Document Number]
 R01AN8230EJ0110

[Description: Japanese]
[概要]
RA4T1マイクロコントローラ(MCU)を使用し、永久磁石同期モータをベクトル制御で駆動するサンプルプログラムです。

[機能、対象システム]
 -センサレスフィードバック
 -ベクトル制御

[対象ハードウェア構成]
 -CPUボード : MCB-RA4T1 RA4T1(R7FA4T1BB3CFM) CPUボード Version 2 (RTK0EMA430C00020BJ)
 -インバータボード : MCI-LV-1
 -通信ボード : MC-COM
 -永久磁石同期モーター : R42BLD30L3

[サポートするQE機能]
 -SW configuration
 -Tuner
 -Analyzer

[ドキュメント番号]
