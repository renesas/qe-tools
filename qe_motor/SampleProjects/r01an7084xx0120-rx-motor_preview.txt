[Description: English]
[Description]
This is the sample program that uses RX26T to drive a permanent magnet synchronous motor with vector 
control over the whole speed range including standstill and low speeds.

[Features, Target System]
 -For RX26T RAM64KB Version CPU Board Version 1
 -Sensorless feedback
 -Vector control

[Hardware Setup]
 -CPU board : RX26T RAM64KB version (R5F526TFCDFP) CPU board MCB-RX26T Type A Version 1(RTK0EMXE70C00000BJ)
 -Inverter board : MCI-LV-1
 -Communication board : MC-COM
 -Permanent magnet synchronous motor : IS-94BZC
 -Sensor : Not used

[Supported QE function(s)]
 -Analyzer

[Document Number]
 R01AN7084EJ0120

[Description: Japanese]
[概要]
RX26Tを使用し、永久磁石同期モータを停止から低速も含めて全速度域をベクトル制御で駆動するサンプルプログラムです。

[機能、対象システム]
 -RX26T RAM64KBバージョンCPUボード Version 1対応
 -センサレスフィードバック
 -ベクトル制御

[対象ハードウェア構成]
 -CPUボード : RX26T RAM64KBバージョン(R5F526TFCDFP) CPUボード MCB-RX26T Type A Version 1(RTK0EMXE70C00000BJ)
 -インバータボード : MCI-LV-1
 -通信ボード : MC-COM
 -永久磁石同期モータ : IS-94BZC
 -センサ : なし

[サポートするQE機能]
 -Analyzer
