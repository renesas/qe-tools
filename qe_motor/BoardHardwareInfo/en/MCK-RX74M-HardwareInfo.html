MCK-RX74M Renesas Flexible Motor Control Kit for RX74M MCU Group

RTK0EMXFN0S00020BJ

The MCK-RX74M is a development kit for easy evaluation of RX74M -based motor control and EtherCAT communication. It includes a permanent magnet synchronous motor (brushless DC motor), an RX74M CPU board, inverter board, and communication board to immediately start motor control evaluation for industrial automation and factory automation applications. Free sample code and QE for Motor can be downloaded from Renesas website, enabling seamless motor control software development.

Product Specification

    MCK-RX74M
    • The CPU board is equipped with the RX74M MCU, which supports EtherCAT
    • Inverter board for 3-phase BLDC motor (48V/10A rating)
    • Onboard debugger for flash programming of RX74M
    • Supports 1-shunt/3-shunt current sensing
    • Overcurrent detection
    • Supports the motor control development support tool, Renesas Motor Workbench
    • Motor control evaluation and debugging can be performed safely with the communication board, which isolates the PC and the CPU board electrically
    • Supports Hall sensors and encoders
